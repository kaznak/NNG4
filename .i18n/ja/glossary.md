## Tactic Names

Tactic names (`rfl`, `rw`, `simp`, etc.) are never translated. Code blocks are kept as-is.

## Style Guide

- Use polite form (です・ます調)
- Omit second-person pronouns where possible
- Maintain the casual game tone while preserving mathematical accuracy
